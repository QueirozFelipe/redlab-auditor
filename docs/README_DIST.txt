=========================================
          REDLAB AUDITOR v1.0.1
=========================================

RedLab is a CLI tool designed to audit the consistency
between Source Control Management (SCM) commits and
Project Management (PM) tasks.

PACKAGE CONTENTS:
- redlab (or redlab.exe): Native binary executable.
- install.sh (or install.ps1): Script for automatic PATH installation.

HOW TO INSTALL:

Linux / macOS:
  1. Open your terminal in the extracted folder.
  2. Run: chmod +x install.sh && ./install.sh
  3. Type 'redlab --help' to verify.

Windows (PowerShell):
  1. Right-click 'install.ps1' and select "Run with PowerShell".
  2. Restart your terminal.
  3. Type 'redlab --help' to verify.

HOW TO USE:
RedLab works based on profiles. To start:
$ redlab profile add
